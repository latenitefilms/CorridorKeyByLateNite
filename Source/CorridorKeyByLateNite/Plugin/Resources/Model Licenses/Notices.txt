CorridorKey by LateNite — CorridorKey v2 model notices

The application includes a converted MLX inference graph, with float16 weight
storage and float32 computation. No Python reference runtime is distributed.
The conversion changes the inference backend and stored precision, not the
trained architecture. Both keying stages and all three foundations are included.
